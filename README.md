# 板塊運動與地球歷史｜國中地科 互動講義

國中地科單元 2（原書 P.26–P.52）的互動式教學網站。

## 內容

- **50 個互動單頁**，一頁一個概念，對應原書頁碼
- **重點 1–4**：地球的構造、板塊運動、岩層記錄的地球歷史、臺灣的板塊和地震
- **圖像記憶區**：點卡片顯示答案
- **會考培訓區／素養題組／情境漫畫題／會考百變題／跨科好試**：共 96 題，點選即判對錯並顯示解析

## 互動形式

| 形式 | 說明 |
|---|---|
| 圖上熱點標註 | 點圖中的號碼，右側面板顯示說明 |
| 拖曳排序 | 地質年代、地質事件先後、海洋地殼的一生等 |
| 拖曳分類 | 大陸／海洋地殼、岩石圈／軟流圈、規模／震度等 |
| 斷層錯動 | 拖曳滑桿，岩塊沿斷層面真實滑動（正／逆／平移） |
| 熱對流動畫 | 講義原圖上疊加動態流線 |
| 原始講義頁對照 | 每頁標示講義頁碼，可開啟掃描原頁 |

滑鼠與觸控皆支援。

## 檔案結構

```
index.html          入口
css/style.css       樣式
js/content.js       課文與題庫資料（含答案與解析）
js/pages-rich.js    概念頁的互動內容覆寫層
js/interactive.js   熱點／拖曳排序／拖曳分類元件
js/app.js           頁面渲染與導覽
js/faultmeta.js     斷層圖層位移參數
img/                講義插圖（自 400dpi 掃描裁切，WebP）
pages/              原始講義掃描頁 27 張
```
