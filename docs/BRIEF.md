## 1　整體評估：現況為何不合格

目前站上的視覺素材分兩類，兩類都未達可發表水準。

### 1.1　圖片（100 張）：全部來自講義掃描件

來源是 400 dpi 的紙本掃描，已做過去背／去透印處理，但先天限制無法克服：

| 問題 | 說明 |
|---|---|
| 紙張質感 | 看得到紙纖維與網點，放大後更明顯 |
| 背面透印 | 已壓制但未根除，淺色區仍有殘影 |
| 邊緣不乾淨 | 裁切邊常帶鄰近文字或表格框線的殘跡 |
| 色彩不一致 | 各頁掃描色溫不同，並排時明顯 |
| 不可縮放 | 點陣圖，高解析螢幕上偏軟 |
| 無法改字 | 標籤文字燒死在圖裡，不能翻譯、不能調整 |

### 1.2　動畫（4 組）：手法錯誤

| 動畫 | 現況 | 問題 |
|---|---|---|
| 三種斷層 | SVG 色塊 | 斷層線延伸到岩塊外的空白處；錯動後留白；只有平塗色帶、無岩層質感；標籤被裁切 |
| 中洋脊 | SVG 色塊 | 構圖過於扁平、示意層級太低，不像地科教材 |
| 隱沒帶 | SVG 色塊 | 同上；隱沒板塊與地表板塊銜接處不自然 |
| 軟流圈熱對流 | **在講義照片上疊虛線** | 手法錯誤。只是線段覆蓋在點陣圖上，照片本身不會動 |

**結論**：圖片需重新繪製，動畫需重新製作。

## 2　技術規格

### 2.1　執行環境

- 純靜態網站，**無建置流程**（no bundler、no framework）
- 原生 JavaScript（ES2017+）、原生 SVG、原生 CSS
- **不得引入任何外部函式庫**（含 D3、GSAP、Three.js、Lottie）
- 目標瀏覽器：Chrome / Safari / Firefox 近兩年版本，含 iOS Safari
- 必須支援**觸控**（學生多用手機）

### 2.2　檔案結構

```
index.html
css/style.css          樣式（已有動畫用 class，見 §4.4）
js/anim.js             ← 動畫模組，本委託主要交付物
js/interactive.js      熱點／拖曳排序／拖曳分類（不在委託範圍）
js/content.js          課文與題庫資料
js/pages-rich.js       各頁區塊定義（圖片與動畫在此被引用）
js/app.js              頁面渲染
img/                   圖片（WebP）
pages/                 講義掃描原頁 27 張（保留，不在委託範圍）
```

### 2.3　動畫介面契約（**必須遵守**）

`js/anim.js` 必須掛上全域物件：

```js
window.ANIM = {
  ridge()      { /* 中洋脊 */   return node; },
  subduction() { /* 隱沒帶 */   return node; },
  fault()      { /* 三種斷層 */ return node; },
  convection() { /* 軟流圈熱對流 */ return node; }
};
```

每個函式**回傳一個 DOM 節點**，且該節點必須提供 `node._stop()` 方法，
供換頁時停止 `requestAnimationFrame`（不停會造成記憶體與電量浪費）。

`js/app.js` 的呼叫方式（已實作，勿更動）：

```js
case 'anim': {
  const n = ANIM[b.kind]();
  (window.__animNodes = window.__animNodes || []).push(n);
  return n;
}
```

在 `js/pages-rich.js` 中以此引用：

```js
{ t: 'anim', kind: 'ridge' }
```

### 2.4　圖片介面契約

- 格式：**SVG 優先**（向量、可縮放、檔案小）；必須點陣時用 WebP
- 檔名：**沿用現有檔名**，只改副檔名。例：`img/fold-main.webp` → `img/fold-main.svg`
- 若改為 SVG，需同步更新 `js/app.js` 中的副檔名組字串（共 11 處，搜尋 `.webp`）
- 單張 SVG 建議 < 120 KB；點陣圖最大寬度 1500 px

### 3.2　文字

- 全部**繁體中文**，用詞須與講義一致（例：地函不寫地幔、軟流圈不寫軟流層）
- 圖內標籤：16–20 px 等效、`font-weight: 800`

### 3.3　品質基準

目標是**教科書插圖等級**，不是簡報示意圖。具體要求：

- 岩層要有**質感**（顆粒、層理紋路），不可純色平塗

- 線條粗細分層：外框 > 地層界線 > 輔助線
- 所有幾何由程式計算，**任何狀態下都不得出現白邊、破圖、元素超出畫布**

## 4　動畫規格（4 組）

### 4.1　`ridge()`　中洋脊：板塊張裂與海底擴張

**使用頁面**：重點 2 →「板塊互相分離（張裂）」（講義 P.29）

**場景**：海底剖面，中洋脊位於正中央。

**必須呈現的過程**（循環播放，每輪約 10 秒）：

1. 軟流圈熱對流**上升**，把兩側板塊往外拉開
2. 地殼被拉裂，岩漿沿裂隙上升
3. 岩漿**噴出海底**，冷卻凝固成新的海洋地殼
4. 新地殼把舊地殼往兩側推開

**教學重點（必須看得出來）**：
- 海洋地殼年齡**由中洋脊向兩側遞增**，且**左右對稱**
- 建議以色帶表示年齡，並附年齡圖例（新 → 老）

**標示**：中洋脊、海水、岩漿、軟流圈熱對流上升、新生海洋地殼

---

### 4.2　`subduction()`　隱沒帶：海溝、熔融、火山

**使用頁面**：重點 2 →「板塊互相推擠｜海洋 × 大陸」（講義 P.29）

**場景**：左側海洋、右側大陸的剖面。

**必須呈現的過程**：

1. 海洋地殼（密度較大）向右移動，在交界處**彎折下沉**
2. 下沉處海底拉出狹長凹陷 → **海溝**
3. 隱沒板塊深入高溫高壓處 → **部分岩石熔融成岩漿**
4. 岩漿沿裂隙上升 → **火山噴發**（需有噴發動作與火山灰）
5. 大陸岩層受擠壓**隆起成山脈**

**教學重點**：
- 必須清楚看出**海洋地殼沒入大陸地殼下方**，不是相反
- 海溝、火山、山脈三種地形的相對位置要正確

**標示**：海溝、海洋地殼、大陸地殼、火山、山脈（造山運動）、軟流圈、熔融成岩漿

---

### 4.3　`fault()`　三種斷層

**使用頁面**：重點 3 →「斷層：岩層被扯斷、錯開」（講義 P.33）

**必須提供三種類型切換**（按鈕已有樣式 `.anim-seg`）：

| 類型 | 作用力 | 上盤相對移動 | 呈現方式 |
|---|---|---|---|
| 正斷層 | 拉張力 | 相對**向下** | 立體塊狀圖或剖面 |
| 逆斷層 | 擠壓力 | 相對**向上** | 立體塊狀圖或剖面 |
| 平移斷層 | 水平作用力 | 水平錯動 | **俯視圖**（剖面看不出水平錯動） |

**必須修正的現有缺陷**：
- 斷層線不得延伸到岩塊之外的空白區
- 錯動後露出的斷層面**必須填上岩面質感**，不得留白
- 岩層必須完整填滿，任何位移量下都不得出現白色缺口
- 標籤（上盤／下盤／斷層面）不得被畫布邊緣裁切

**教學重點**：
- **上盤＝位在斷層面上方的岩塊**，這點要能一眼看出
- 平移斷層建議以**河流或道路被錯開**呈現

---

### 4.4　`convection()`　軟流圈熱對流：板塊運動的引擎　**（全新）**

**使用頁面**：重點 2 →「軟流圈熱對流：板塊運動的引擎」（講義 P.30）

> **此頁目前是在講義照片上疊虛線，必須整個換掉。**

**場景**：一幅橫跨全寬的剖面，同時包含**中洋脊（中央）** 與**兩側海溝**。

**必須呈現**：

1. 軟流圈中**兩個對流胞**：在中洋脊下方**上升**、在海溝下方**下降**
2. 對流帶動上方岩石圈板塊移動（箭頭：由中洋脊向兩側）
3. 中洋脊處生成新地殼；海溝處板塊隱沒消失
4. 對流以**流動的粒子**呈現，不要只用虛線

**教學重點（本單元核心）**：
- 熱對流**上升**處 → 板塊**分離** → 中洋脊
- 熱對流**下降**處 → 板塊**推擠** → 海溝

**標示**：中洋脊、海溝、岩石圈、軟流圈、熱對流上升、熱對流下降

---

### 4.5　四組共通要求

**控制項**（CSS class 已存在，直接套用）：

| 元素 | class | 功能 |
|---|---|---|

**效能**：單一 `requestAnimationFrame` 迴圈；換頁時 `_stop()` 必須真的停止

**響應式**：SVG 用 `viewBox` + `width:100%`；手機（390 px 寬）上標籤仍須可讀

## 6　特別注意：題目附圖不可自由發揮

清單中標示為「**題目附圖**」與「**選項圖**」者，是考題的一部分。
重繪時**必須與講義原圖在資訊上完全等價**：

- 相同的結構、相同的標號（甲乙丙丁、①②③④、X/Y/Z）
- 相同的相對位置與傾斜方向（斷層傾向、岩層順序特別關鍵）
- 選項圖必須維持 (A)(B)(C)(D) 四格並排，且四格差異與原圖一致

**任何一處改動都可能讓題目答案改變或無解。**
標示為「互動熱點底圖」者另有要求：標註點座標以百分比定位，
重繪後需回報各標註點的新座標（見 `js/pages-rich.js` 中的 `points` 陣列）。
